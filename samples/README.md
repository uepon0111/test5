# サンプル音源について

このフォルダは、イコライザ画面で「サンプル音源で試す」機能に使用する音源ファイルを配置する場所です。

## デフォルト動作

サンプル音源はブラウザの Web Audio API を使って自動生成されます。
このフォルダにファイルがなくても、以下の合成サンプルが使用されます：

- **バランス**: 全帯域の音が均等に含まれるサンプル
- **バス (低音)**: 低音域が強調されたサンプル
- **トレブル (高音)**: 高音域が強調されたサンプル
- **ボイス (声)**: 中音域（声帯の周波数帯）のサンプル

## カスタムサンプルの追加方法

自分のサンプル音源を使用したい場合は、著作権フリーの音源ファイルを
このフォルダに配置し、`js/equalizer.js` の `SAMPLES` オブジェクトを
編集してください。

## 対応フォーマット

ブラウザが対応している形式であれば使用可能です：
- MP3 (.mp3)
- WAV (.wav)
- OGG (.ogg)
- AAC / M4A (.m4a)

## 著作権フリー音源の入手先

- [Freesound](https://freesound.org/)
- [ccMixter](http://ccmixter.org/)
- [Free Music Archive](https://freemusicarchive.org/)
