# 鉄道シミュレーター

zip を展開し、**フォルダ構成を保ったまま** `index.html` をブラウザで開いてください(サーバー不要)。

| js/02-state.js | ヒント文言・寸法定数・DOM参照・共有状態(線路/列車/駅/カメラ) |
| js/03-track.js | 線路データ: 辺の追加・削除・接続数・rebuild |
| js/04-storage.js | 保存(localStorage)と読み込み |
| js/05-laying.js | 線路の敷設(経路計算と敷設) |

| js/07-trains.js | 列車の命名・追加・削除 |
| js/08-stations.js | 駅とホーム: 計画・干渉判定・設置プレビュー |
| js/09-train-tools.js | 列車の向き反転と、配置位置のプレビュー |

## 編集するときの注意
- JS は通常の `<script>` として、`index.html` に書かれた順に読み込みます。ファイル間で変数・関数をグローバルに共有しているため、**読み込み順を入れ替えない**でください。
- ES Modules(`import`/`export`)に変えると、ファイルを直接開いたときに動かなくなります。
- ファイルを追加するときは、`index.html` の `<script>` を、依存先より後ろに追加してください。
- 元の `index.html` のコードは、行を分けただけで1文字も変更していません(動作は元と同一です)。

## 追加機能
- **列車の編成**: 「列車」→「ダイヤ設定」の「編成」で1〜12両 (1両=1マス)。「追加」タブでは、次に置く列車の編成を決められます。複製した列車は親の編成を引き継ぎます (個別に変更も可)。列車の位置は編成の中心で、駅では編成の中心がホームの中央に止まります
- **ホームの長さ**: 駅を選ぶと、番線ごとに「長さ」(2〜10両分) を設定できます。島式ホームは両側の番線で同じ長さになります。長さに応じて屋根・階段・照明の配置が変わり、白い目印は1両ぶんの乗車位置です。長いホームは本線や並行する線路が自動で延びます (空きがないときは延ばせません)
- 保存データ: 列車の `nc` (両数) と、`pl` の6番目の要素 (番線ごとの長さ) を追加。古い保存データは、編成=4両・ホーム=4マスとして読み込みます
